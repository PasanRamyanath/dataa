## 1. Executive Summary & Core Objective

During live testing of the BTCUSDT 10-second alpha pipeline (`scratch/live_45m_eval_ledger.jsonl`), all ensemble member predictions collapsed into extreme collinearity:
- **Live Pairwise Correlations:** $r = 0.837 \text{ to } 0.997$ (sequence models `tft`, `patchtst`, `nhits`, and `ssm-challenger` correlated at $r = 0.987 \text{ to } 0.997$).
- **Consequence:** The ensemble ceased functioning as a diversified multi-signal system and behaved as a single redundant model repeated 8 times. Downstream stacking meta-learners suffered severe multicollinearity (matrix condition numbers $> 100$, inverted feature weights, intercept collapse), and the secondary meta-labeler collapsed into an artificial bimodal distribution ($0.42$ floor vs $0.85+$ jumps).
- **Core Forensic Finding:** This collinearity was **not** inherent to the offline models. In out-of-fold (OOF) validation parquets (`fusion/oof/*.parquet`), offline member correlations were modest ($r = 0.011 \text{ to } 0.526$, mean $r \approx 0.22$). The live collapse was artificially induced by **inference wrapper engineering**:
  1. A shared micro-heuristic `_live_micro_signal(recent_df)` injected identical signal (30% to 50% weight) into all models.
  2. Severe intra-bar lookahead leakage via unclosed price returns (`_live_ret_pct`).
  3. A uniform, steep sigmoid mapping (`_signal_to_3class_proba`) that saturated directional votes into identical buckets.
  4. Post-inference Bayesian orderflow tilting in `live_loop_v2.py` re-applying the same microstructure inputs.

**Mission Deliverable:**  
This report provides the exact architectural specification to dismantle this collinearity, replacing the redundant models with **3 genuinely orthogonal specialist models** (Microstructure, Cross-Asset Lead-Lag, and Basis/Term Structure) operating on disjoint feature subsets with zero shared heuristic blending, achieving **pairwise Pearson and Spearman $r \le 0.70$ (empirically targeted at $r \le 0.40$)** across the validation set to satisfy AC1.

### 2.4 Root Cause 3: Uniform Steep Sigmoid Post-Processing
Every member predictor passes its scalar output through `_signal_to_3class_proba` (`checkpoint_loaders.py` lines 126–151):

## 6. AC1 Correlation Evaluation Methodology

### 6.1 Mathematical Formulation of AC1 Validation

Let $S_A(t)$, $S_B(t)$, and $S_C(t)$ represent the directional prediction scores (or $P_{up} - P_{down}$) emitted by Model A, Model B, and Model C at bar timestamp $t$ across the out-of-fold validation set:

1. **Pairwise Pearson Correlation ($r_P$):**
   $$r_P(X, Y) = \frac{\sum_{t=1}^N (X_t - \bar{X})(Y_t - \bar{Y})}{\sqrt{\sum_{t=1}^N (X_t - \bar{X})^2 \sum_{t=1}^N (Y_t - \bar{Y})^2}}$$
2. **Pairwise Spearman Rank Correlation ($r_S$):**
   $$r_S(X, Y) = 1 - \frac{6 \sum_{t=1}^N d_t^2}{N(N^2 - 1)}, \quad d_t = \text{rank}(X_t) - \text{rank}(Y_t)$$

**Acceptance Gate Criterion (AC1):**
$$\max_{(i, j) \in \{A, B, C\}, i \ne j} \max\left(|r_P(i, j)|, |r_S(i, j)|\right) \le 0.70$$

### 6.2 Evaluation Harness Script Specification

The evaluation script `scripts/evaluate_ensemble_and_meta.py` (Feature Inventory #17) must execute the following automated validation protocol:

```python
def verify_ensemble_decorrelation(oof_predictions: dict[str, pl.DataFrame]) -> dict:
    """
    Computes pairwise Pearson and Spearman correlation matrices across
    all pairs of ensemble members. Verifies that all pairwise values <= 0.70.
    """
    members = sorted(oof_predictions.keys())
    assert len(members) >= 3, f"AC1 requires >= 3 members, found {len(members)}"
    
    # Inner-join on timestamps to align bars
    base = oof_predictions[members[0]].select(["ts", (pl.col("prob_up") - pl.col("prob_down")).alias(members[0])])
    for m in members[1:]:
        sub = oof_predictions[m].select(["ts", (pl.col("prob_up") - pl.col("prob_down")).alias(m)])
        base = base.join(sub, on="ts", how="inner")
        
    assert base.height >= 500, f"Insufficient validation sample size: N={base.height}"
    
    results = {}
    violations = []
    for m1, m2 in itertools.combinations(members, 2):
        x = base[m1].to_numpy()
        y = base[m2].to_numpy()
        pearson_r, _ = stats.pearsonr(x, y)
        spearman_r, _ = stats.spearmanr(x, y)
        results[(m1, m2)] = {"pearson": float(pearson_r), "spearman": float(spearman_r)}
        
        if abs(pearson_r) > 0.70 or abs(spearman_r) > 0.70:
            violations.append((m1, m2, pearson_r, spearman_r))
            
    if violations:
        raise AssertionError(f"AC1 FAILED: Pairwise correlations exceed 0.70 threshold: {violations}")
        
    return results
```
